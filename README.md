# Лист задач

Это простое локальное приложение: список задач, отметка выполнения и прогресс.

## Как открыть (самый простой способ)

### Windows
1. Открой папку проекта.
2. Найди файл `index.html`.
3. Нажми по нему **2 раза**.
4. Откроется браузер с приложением.

> Если открылся код файла, а не страница — нажми правой кнопкой по `index.html` → **Открыть с помощью** → выбери Chrome/Edge.

### macOS
1. Открой папку проекта в Finder.
2. Нажми 2 раза на `index.html`.
3. Если не открылось в браузере: правой кнопкой → **Open With** → Safari/Chrome.

---

## Что умеет

- Нажатие на **название задачи** запускает действие (ссылка/подсказка/подзадачи/попытка открыть программу).
- Все ссылки встроены прямо в названия задач.
- Для путей вида `C:\...\program.exe` приложение пытается открыть файл через `file:///...`.
- Если браузер блокирует запуск `.exe`, путь автоматически копируется в буфер обмена.

---

## Вариант через локальный сервер (если нужно)

1. Открой терминал в папке проекта.
2. Выполни команду:

```bash
python3 -m http.server 8080
```

3. Открой в браузере:

```text
http://localhost:8080
```

4. Чтобы остановить сервер, в терминале нажми `Ctrl + C`.

---

## Важно

- Твои галочки сохраняются в браузере автоматически (`localStorage`).
- Если открыть в другом браузере или очистить данные браузера, прогресс может сброситься.
