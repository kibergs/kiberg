# Лист задач

Это простое локальное приложение: список задач, отметка выполнения и прогресс.

## Как открыть (самый простой способ)

### Windows
1. Открой папку проекта.
2. Найди файл `index.html`.
3. Нажми по нему **2 раза**.
4. Откроется браузер с приложением.

### macOS
1. Открой папку проекта в Finder.
2. Нажми 2 раза на `index.html`.

## Новая механика «Согрешил»

- В блоке «Запрещено» у каждого пункта есть кнопка **«Согрешил»**.
- По нажатию выпадает случайное наказание.
- Наказания появляются в блоке «Наказания к выполнению».
- Пока есть хотя бы одно незакрытое наказание, отмечать выполненными обычные задачи нельзя.

## Важно

- Твои галочки и наказания сохраняются в браузере автоматически (`localStorage`).
- Если очистить данные браузера, прогресс и наказания сбросятся.
